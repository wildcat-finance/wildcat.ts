## Shared KYC provider

`getDeploymentAddress(chainId, "KYCRoleProvider")` returns the shared provider
address on Sepolia. The hooks administrator uses `prepareAddHookRoleProvider`
to attach it to existing hooks and set its credential TTL. Only the provider
administrator can enroll or remove wallets. Use `prepareAddRoleProviderMembers`
and `prepareRemoveRoleProviderMembers` to build those transactions.

`getKycEnrollmentTimestamp(provider, roleProvider, account)` returns the start
of the wallet's current enrollment in Unix seconds, or `0n` if unlisted.
`getCredential` returns the current block timestamp for an enrolled wallet.
The hook measures its TTL from that lookup. After removal, fresh lookups return
zero immediately. A hook can still honor a cached approval until it expires.

Indexed and live market reads report the provider kind as `"kyc"`.
`getRoleProviderAuthority` returns its deployment block and transaction hash.
The KYC constructor emits no event, so this deployment has no `deployedAt.logIndex`.

## Markets and wrappers

- Borrower previews recognize the repayment freeze on all three v2.5.9
  templates. If a market closes before repayment, previews for changing the
  minimum deposit or the fixed-term end time return `MarketClosed`.
- `WrapperFactory.getDeploymentCapability` returns `ProtectionNotApproved` if
  the market's hooks factory hasn't approved the v2.5.9 wrapper factory.
  Revoking approval leaves registered wrappers protected.
- For a market bound to an older v2.5 wrapper factory, the same check returns
  `UnsupportedFactory`. The SDK can still find its existing wrapper.
- `GetNukeProtectionFactoryApprovalDocument` reads a hooks factory's approval
  for a feature factory. `GetMarketNukeProtectionDocument` looks up an
  account's nuke protection registration on a market.

## Verification

The SDK built and all 802 tests passed. The ABI check matched 420 functions,
events, and errors against the protocol artifacts. Live gateway queries
confirmed both hooks factories, six enabled template registrations, the KYC
deployment, and both wrapper factory approvals. Full schema introspection
exceeds the public gateway's query depth limit, so schema generation used
Hinterlight.

On a local Sepolia fork at block 12171240, the SDK deployed open-term,
fixed-term, and periodic-term markets through both hooks factories with KYC
attached. Each market registered its wrapper for nuke protection.

An enrolled lender deposited into an open-term market. After removal, the
lender deposited again using the hook's cached approval. Once the one-hour
TTL expired, the SDK reported `RequiresAccess` and the market rejected the deposit.
