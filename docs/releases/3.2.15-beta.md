## Default status across market generations

`getMarketDefaultStatus(client, { market, first?, limits?, signal? })` is the
shared default-status reader for the app and other consumers. Its result has
`isDefaulted: boolean | undefined`, `source`, an optional effective `defaultedAt`,
and observation timestamps. `source` distinguishes `recorded` from `legacy-history`.

For markets with `market.defaultedAt`, the helper returns the committed flag
without a history query. Zero remains false; it never falls back to legacy math
because the flag is false. A recorded default survives repayment and closure.
`Market.hasRecordedDefault` retains its existing meaning and behavior. As in
3.2.14, a zero flag means no committed default at the observation; it is not a
forecast of what a later state update will record.
The flag covers both prolonged delinquency and missed repayment deadlines;
consumers do not need a separate repayment-default classification.

For older markets, the helper reads complete delinquency transitions from
creation and reconstructs two separate clocks:

- The fee clock grows while delinquent and decays while healthy. Curing does
  not immediately clear the existing penalty timer.
- The default run requires uninterrupted delinquency. It starts its 90-day
  allowance after any remaining grace; an observed cure resets this run even
  if penalty fees are still burning down. A cure exactly at the cutoff is on
  time; a later observation establishes default at that cutoff.

A reconstructed historical default persists after cure or closure, like the
new recorded flag. This replaces the app's current-state approximation
`timeDelinquent - delinquencyGracePeriod >= 90 days`, which cannot distinguish
separate delinquency runs and loses history after closure. `defaultedAt` in a
`legacy-history` result is derived evidence, not an on-chain recorded flag;
the helper does not modify the `Market` model.

History reads use the existing fields on both legacy V2 and V2.5 schemas, so
no subgraph deployment is required. Pages are pinned to the first indexed
block and deployment, checked against the transition counter, and replayed
against the indexed clock/state before a result is returned. The observed
state is extended only through that indexed block's timestamp, never through
the browser clock. Direct token transfers become visible to this history
only when the protocol/indexer observes them through a state update.

Missing markets, missing index metadata, indexing errors, incomplete history,
or an inconsistent replay return `isDefaulted: undefined` with a `reason`.
Network failures, identity mismatches, cancellation and traversal limits reject,
consistent with other SDK history readers. A partial history is never reported
as a confirmed negative. All pages use `no-cache`, and continuation pages retain
the first block's timestamp/hash when Graph Node omits those optional fields
on pinned metadata reads.

## Consumer integration

```ts
import { getMarketDefaultStatus } from "@wildcatfi/wildcat-sdk";

const status = await getMarketDefaultStatus(subgraphClient, {
  market,
  signal: abortController.signal
});

// Render unknown as unavailable, not healthy/zero defaults.
const label = status.isDefaulted === undefined
  ? "Unavailable"
  : status.isDefaulted ? "Defaulted" : "No default recorded";
```

For profile counts, sum confirmed defaults only after every relevant market's
status has resolved. If a required status is unknown or its read failed, show
the total as unavailable rather than silently reporting a smaller count. Cache
results by chain and market with the app's normal query lifecycle; refresh
after market updates. Do not exclude closed markets before evaluating their
default history. The existing healthy/delinquent/penalty/terminated status and
fee countdown remain separate from this historical default status.

App integration is the next step after the operator publishes this package.
The app remains on `3.2.14-beta` during SDK preparation. Deployment addresses,
subgraph routes, dependencies, generated bindings and the dependency lockfile
are unchanged from [3.2.14-beta](./3.2.14-beta.md).

## Verification

- Production TypeScript build, changed-file ESLint and package dry-run passed.
  The package contains the new runtime helper, declarations and release notes.
- Full offline Mocha suite: 786 passing, one optional archive-RPC test skipped.
  Tests exercise cutoff boundaries, grace recovery, interrupted delinquency
  with an outstanding penalty timer, defaults after cure/closure, same-block
  transitions, page completeness, snapshot consistency and unknown results.
- Both query documents validate against the existing V2.5 schema and pass the
  app's subgraph-request validator at app revision
  `bde338ffcceef19680e594273f0c331f2f44e617`.
- Read-only gateway checks on 2026-10-04 covered 11 Mainnet markets at blocks
  26121486–26121487 and 12 Sepolia markets at block 11844466, selected across old,
  recent, delinquent and closed markets. Three-record pages exercised real
  continuation reads; all 23 returned a resolved legacy result. The recorded
  flag path is covered by offline tests; these samples were legacy markets.
  [Captured results](./evidence/3.2.15-beta-default-status-2026-10-04.json)
  preserve the per-market observations and index provenance. These are indexed
  observations, not an independent on-chain audit or an app deployment check.
