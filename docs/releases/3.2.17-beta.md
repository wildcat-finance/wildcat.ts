# SDK 3.2.17-beta

Prepared on 2026-10-05 on `release/v3.2.17-beta`, based on
`release/v3.2.16-beta` at `8efc853df6d1aeb6ff0d21251920b930e81eec6e`.
Adopts Sepolia protocol V2.5.7 and subgraph V2.5.15 while retaining the shared
default-status API and zero-penalty-APR correction from the previous release.
Synced-provider and default-gateway checks passed on 2026-10-05. The candidate
is ready for operator commit, push and beta publication.

The default subgraph route is
`https://graph.wildcat.finance/sepolia/v2.5.15`. The gateway's upstream endpoints
are [Goldsky](https://api.goldsky.com/api/public/project_cmheai1ym00jyx7p27qn46qtm/subgraphs/sepolia/v2.5.15/gn)
and [Hinterlight](https://graph.hinterlight.net/sepolia/v2.5.15).

V2.5.7 changes delegated-transfer sanctions checks on newly deployed markets
and wrapper shares. It uses the same external interfaces as V2.5.6 and reuses
the three V2.5.6 hook stores. Repayment-parameter freeze detection therefore
continues recognizing those template addresses. No ABI, GraphQL schema, query,
public API, or dependency update is needed. Other chain configurations,
identity registry, AccessList provider factory, and historical read paths are
unchanged.

## Existing markets and wrappers

The displaced V2.5.5 hooks factories remain indexed for their existing markets,
which stay available through indexed provenance and compatible lens reads.
`getConfiguredMarketKindForHooksFactory` continues describing configured
transaction targets, not an exhaustive historical factory registry. The
subgraph retains previous generations and their original start blocks.

The existing wrapper policy now selects only the V2.5.7 wrapper factory for
new V2.5 wrapper deployment. A market immutably bound to the V2.5.5 wrapper
factory returns `UnsupportedFactory` from deployment capability checks; adding
that factory to the supported historical list would allow new wrappers without
the delegated-transfer fix. Existing registered or indexed wrappers remain
discoverable and usable. The legacy V1 factory fallback is unchanged. This
release does not upgrade deployed immutable markets or wrappers.

constants layout and historical factory registry. The direct handoff,

registration and synced-data verification are complete. Commit and push the
SDK candidate before consumer cutover.


forward `/sepolia/v2.5.15`. Carry forward the lifecycle controls on
`feat/v2.5-market-lifecycle-controls` at
`da13712b5802917410dbafe764dfd272527268fe`. New-market and wrapper wallet
acceptance remains an app integration step. The existing fork scripts preserve
