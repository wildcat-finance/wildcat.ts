## Legacy markets with zero penalty APR

`getMarketDefaultStatus` now accepts a frozen zero fee timer when reconstructing
a legacy market's default history. Legacy contracts can skip `timeDelinquent`
updates when the immutable `delinquencyFeeBips` is zero. In `3.2.15-beta`, an
otherwise valid state update could consequently change a resolved default to
`inconsistent-history`.

The default rule remains elapsed, uninterrupted delinquency after remaining
grace, regardless of the penalty APR. A zero fee does not exempt the borrower
from the 90-day rule. The operator confirmed this interpretation on 2026-10-04.
Observed cures reset the run; historical defaults survive later cures and
closure, as described in [3.2.15-beta](./3.2.15-beta.md).

The history query adds the existing `delinquencyFeeBips` field. Validation
accepts a zero stored timer for a zero-fee market, or the fully reconstructed
timer for implementations that advance it. Other timer mismatches still return
unknown. There is no public API change, contract change, subgraph deployment,
dependency change or generated-binding update.

## V2.5 contract compatibility

The protocol's V2.5.6 handoff records contract source
`fe431bbdfc157b8778ac3690772c6556c74a0a9d`. In that revision,
`WildcatMarketBase._accrueTransition` calls `MarketLifecycleLib.accrueDefaultRun`
independently of fee calculation, and `_updateScaleFactorAndFees` advances the
delinquency timer even when penalty APR is zero. `defaultedAt()` returns the
committed marker: an idle market requires a state-changing call before that
marker is written. A call after the inclusive cutoff records the cutoff's
historical timestamp; a cure at the cutoff remains timely.

The relevant contract and test sources match the inspected checkout at
`1fbbacb318046c53822a70c2808fbc55372d5a3a`. Five existing focused Foundry tests
passed, including zero-fee accrual/recovery on both market types and two
1,000-run cutoff/cure fuzz tests whose fixture includes zero-fee markets.
This verifies source behavior; no new deployment or live V2.5 default
transaction was performed.
